# ربات معامله — لانگ و شورت با حد ضرر روی Hyperliquid

این ربات روی **Hyperliquid** پوزیشن لانگ یا شورت باز می‌کند؛ همان صرافی‌ای که بخش
Perps داخل Phantom پشت صحنه از آن استفاده می‌کند. ربات مستقیم وصل می‌شود، پس
کارمزد اضافهٔ ۰.۰۵٪ Phantom را نمی‌دهید.

- **حد ضرر و حد سود همراه خود سفارش ورود**، در یک درخواست، روی صرافی ثبت می‌شوند.
  حتی اگر ربات یا اینترنت قطع شود، حد ضرر سر جایش است.
- **اندازهٔ پوزیشن خودکار حساب می‌شود** تا اگر حد ضرر خورد، فقط درصد مشخصی از
  سرمایه (پیش‌فرض ۱٪) از دست برود.
- **کلید اصلی Phantom هیچ‌وقت به ربات داده نمی‌شود.**

> **ربات هنوز خودش تحلیل نمی‌کند.** جهت، حد ضرر و حد سود را شما می‌دهید.

## ⚠️ پیش از شروع

1. **با سرور واقعی آزمایش نشده.** کد روی SDK رسمی Hyperliquid ساخته شده و ۹۲ تست
   دارد. در یکی از تست‌ها، خود SDK رسمی درخواست واقعی را می‌سازد و امضا می‌کند، و
   تست بررسی می‌کند که قالب قیمت‌ها و حجم‌ها درست است. ولی محیط توسعه به سرورهای
   Hyperliquid دسترسی نداشت. **اولین اجرا حتماً روی Testnet باشد.**
2. **محدودیت کشوری:** قوانین Hyperliquid کاربران ایران را منع کرده است. ریسکش را
   می‌دانید. در حساب فقط مبلغی نگه دارید که حاضرید از دست بدهید.

## راه‌اندازی

### ۱. نصب

```bash
make setup
cp trader.env.example .env.trader
```

### ۲. وصل کردن Phantom (یک بار)

1. آدرس حساب Hyperliquid شما همان **آدرس Ethereum در Phantom** است (با `0x` شروع
   می‌شود). این آدرس را در `TRADER_ACCOUNT` بگذارید.
2. به `app.hyperliquid.xyz/API` بروید (برای Testnet: `app.hyperliquid-testnet.xyz/API`)،
   با **Phantom** وصل شوید، یک **API Wallet** بسازید و روی **Authorize** بزنید. Phantom
   فقط یک بار تأیید می‌خواهد.
3. کلید خصوصی **همان API Wallet** (نه کلید Phantom) را در `TRADER_API_PRIVATE_KEY`
   بگذارید.

> **هرگز کلید خصوصی یا عبارت بازیابی (seed phrase) Phantom را در این فایل نگذارید.**
> طبق مستندات Hyperliquid، API Wallet فقط می‌تواند معامله کند و نمی‌تواند پول برداشت
> کند. اگر اشتباهاً کلید Phantom را بگذارید، ربات هشدار می‌دهد. اگر کلید API لو رفت،
> از همان صفحهٔ API باطلش کنید.

### ۳. بررسی اتصال

```bash
python -m services.trader.cli status
```

باید همان موجودی را نشان دهد که در بخش Perps داخل Phantom می‌بینید. اگر صفر نشان
داد ولی در Phantom پول دارید، احتمالاً آدرس درست نیست یا پول در حساب spot است و باید
به perps منتقل شود.

## استفاده

هر دستوری که بدون `--execute` اجرا شود **هیچ سفارشی نمی‌فرستد** و فقط نشان
می‌دهد چه کاری انجام خواهد شد:

```bash
# لانگ SOL، حد ضرر ۱۴۰، حد سود ۱۷۰ (فقط نمایش)
python -m services.trader.cli open --symbol SOL --side long --sl 140 --tp 170

# خروجی نمونه با موجودی ۱۰۰۰ دلار و قیمت ۱۵۰:
#   market            SOL LONG
#   entry (now)       150
#   stop loss         140
#   take profit       170
#   size              0.92 SOL  ($138.00)
#   leverage          1x
#   risk budget       $10.00
#   loss at stop      -$9.96  (fees and slippage included)
#   profit at target  +$18.27  (after fees)
#   reward : risk     1.83 : 1

# ارسال واقعی
python -m services.trader.cli open --symbol SOL --side long --sl 140 --tp 170 --execute

# شورت با حد سود ۲ برابر فاصلهٔ حد ضرر و ریسک ۰.۵٪
python -m services.trader.cli open --side short --sl 165 --rr 2 --risk 0.5 --execute

# جابه‌جا کردن حد ضرر (مثلاً به نقطهٔ سر به سر)
python -m services.trader.cli tpsl --symbol SOL --sl 150 --execute

# بستن پوزیشن با قیمت بازار
python -m services.trader.cli close --symbol SOL --execute
```

`--symbol` هر بازار Hyperliquid را می‌پذیرد، مثل `BTC`، `ETH` و `SOL`.

## قوانینی که ربات همیشه رعایت می‌کند

| قانون | دلیل |
|---|---|
| ورود، حد ضرر و حد سود در **یک درخواست** فرستاده می‌شوند، همان‌طور که اپ خود Hyperliquid می‌فرستد | پوزیشن حتی یک لحظه بدون محافظ نمی‌ماند |
| بعد از باز شدن پوزیشن، وجود حد ضرر روی صرافی بررسی می‌شود. اگر نبود، دوباره ثبت می‌شود و اگر باز هم ثبت نشد، **پوزیشن فوراً بسته می‌شود** | پوزیشن بدون حد ضرر می‌تواند کل حساب را از بین ببرد |
| حد ضرر با قیمت بازار اجرا می‌شود، نه limit | در ریزش سریع، سفارش limit ممکن است پر نشود و پوزیشن بی‌محافظ بماند |
| هنگام جابه‌جا کردن حد ضرر، اول حد ضرر جدید ثبت می‌شود و بعد قبلی حذف می‌شود | پوزیشن در این فاصله هم بی‌محافظ نمی‌ماند |
| اندازهٔ پوزیشن از روی حد ضرر حساب می‌شود و کارمزد و لغزش قیمت را هم در نظر می‌گیرد | ضرر در صورت خوردن حد ضرر از بودجهٔ ریسک بیشتر نمی‌شود |
| ریسک هر معامله حداکثر ۵٪ است (پیش‌فرض ۱٪) و اهرم حداکثر ۳ برابر (قابل تنظیم تا ۲۰) | ۵ ضرر پشت سر هم با ریسک ۵٪ یعنی حدود ۲۳٪ ضرر کل حساب |
| در هر بازار فقط یک پوزیشن باز | حجم و ریسک پوزیشن بی‌صدا تغییر نمی‌کند |
| اگر ارسال سفارش timeout شد، ربات دوباره تلاش **نمی‌کند** | ممکن است سفارش رسیده باشد و تلاش دوباره پوزیشن را دو برابر کند |
| پیش‌فرض Testnet است. Mainnet هم `TRADER_NETWORK=MAINNET` لازم دارد، هم `TRADER_ALLOW_MAINNET=true`، و قبل از هر ارسال باید `yes` تایپ کنید | با یک اشتباه در تنظیمات پول واقعی درگیر نمی‌شود |

## صرافی دوم: Pacifica

با `TRADER_VENUE=PACIFICA` همین ربات، با همین قوانین، روی Pacifica (سولانا) کار
می‌کند. در این حالت `TRADER_ACCOUNT` آدرس سولانای Phantom است و کلید API را در
`app.pacifica.fi/apikey` می‌سازید.
