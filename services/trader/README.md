# معامله‌گر Pacifica — لانگ و شورت روی سولانا با Phantom

این ابزار روی [Pacifica](https://pacifica.fi)، صرافی فیوچرز سولانا، پوزیشن لانگ یا
شورت باز می‌کند. **حد ضرر همراه خود سفارش فرستاده می‌شود** و حد سود اختیاری است.
اندازهٔ پوزیشن را خودش حساب می‌کند تا اگر حد ضرر فعال شد، فقط درصد مشخصی از
سرمایه (پیش‌فرض ۱٪) از دست برود.

> **این ابزار هنوز خودش تصمیم نمی‌گیرد.** جهت معامله، حد ضرر و حد سود را شما
> تعیین می‌کنید. تحلیل خودکار چارت و خبر مرحلهٔ بعد است.

## چرا Pacifica و نه صرافی‌های دیگر سولانا؟

| صرافی | وضعیت (سپتامبر ۲۰۲۶) |
|---|---|
| **Drift** | در آوریل ۲۰۲۶ حدود ۲۸۰ میلیون دلار هک شد و با نام Velocity فقط در بتای خصوصی است |
| **Jupiter Perps** | خود Jupiter می‌گوید API آن هنوز در حال توسعه است |
| **Pacifica** | پرحجم‌ترین صرافی فیوچرز سولانا، با API رسمی، SDK پایتون، حد سود و ضرر داخل سفارش، و کلید API جدا از کیف پول |

## ⚠️ پیش از شروع

1. **محدودیت کشورها:** طبق شرایط استفادهٔ Pacifica، ساکنان آمریکا، ایران،
   افغانستان، کوبا، سوریه، کرهٔ شمالی و کریمه اجازهٔ استفاده ندارند. اگر شامل این
   محدودیت می‌شوید، استفاده از Pacifica نقض شرایط آن است و ممکن است حسابتان
   مسدود شود.
2. **هنوز با سرور واقعی آزموده نشده.** کد دقیقاً بر اساس مستندات و SDK رسمی
   Pacifica نوشته شده (امضای درخواست‌ها بایت به بایت با SDK رسمی تطبیق داده
   شده) و ۷۰ تست دارد، ولی محیط توسعه به سرورهای Pacifica دسترسی نداشت.
   **اولین اجرا حتماً روی Testnet باشد.**
3. **دسترسی کلید API به برداشت وجه بررسی نشده.** نتوانستم تأیید کنم که کلید API
   در Pacifica نمی‌تواند پول برداشت کند. پس در حساب Pacifica فقط مبلغی نگه دارید
   که حاضرید برای معامله ریسک کنید.

## راه‌اندازی

### ۱. نصب

```bash
make setup
cp .env.trader.example .env.trader
```

### ۲. وصل کردن Phantom (کلید Phantom هیچ‌وقت به ربات داده نمی‌شود)

1. در مرورگر به Pacifica بروید (برای Testnet، لینک در بخش Testnet از
   [مستندات Pacifica](https://docs.pacifica.fi) آمده) و **Connect Wallet → Phantom**
   را بزنید.
2. در Testnet طبق راهنمای Testnet در مستندات Pacifica پول آزمایشی بگیرید. در Mainnet، USDC واریز کنید.
3. به صفحهٔ **API Keys** بروید (در Mainnet آدرسش `app.pacifica.fi/apikey` است) و یک
   کلید بسازید. Phantom از شما می‌خواهد آن را تأیید کنید.
4. در `.env.trader` این دو مقدار را پر کنید:
   - `PACIFICA_ACCOUNT` = آدرس عمومی کیف پول Phantom
   - `PACIFICA_AGENT_PRIVATE_KEY` = کلید خصوصی **همان کلید API** که ساختید

> **هرگز کلید خصوصی یا عبارت بازیابی (seed phrase) خود Phantom را در این فایل
> نگذارید.** ربات با کلید API امضا می‌کند و Pacifica آن را به نام حساب Phantom
> شما اجرا می‌کند. اگر اشتباهاً کلید خود Phantom را بگذارید، ربات هشدار می‌دهد.
> اگر کلید API لو رفت، از همان صفحهٔ API Keys باطلش کنید.

### ۳. بررسی اتصال

```bash
python -m services.trader.cli status
```

## استفاده

هر دستوری که بدون `--execute` اجرا شود **هیچ سفارشی نمی‌فرستد** و فقط نشان
می‌دهد چه کاری انجام خواهد شد:

```bash
# لانگ SOL، حد ضرر ۱۴۰، حد سود ۱۷۰ (فقط نمایش)
python -m services.trader.cli open --symbol SOL --side long --sl 140 --tp 170

# خروجی نمونه با موجودی ۱۰۰۰ دلار و قیمت ۱۵۰:
#   market            SOL LONG
#   entry (mark)      150
#   stop loss         140
#   take profit       170
#   size              0.92 SOL  ($138.00)
#   leverage          1x
#   risk budget       $10.00
#   loss at stop      -$9.98  (fees and slippage included)
#   profit at target  +$18.25  (after fees)
#   reward : risk     1.83 : 1

# ارسال واقعی
python -m services.trader.cli open --symbol SOL --side long --sl 140 --tp 170 --execute

# شورت با حد سود ۲ برابر فاصلهٔ حد ضرر، ریسک ۰.۵٪
python -m services.trader.cli open --side short --sl 165 --rr 2 --risk 0.5 --execute

# جابه‌جا کردن حد ضرر (مثلاً به نقطهٔ سر به سر)
python -m services.trader.cli tpsl --symbol SOL --sl 150 --execute

# بستن پوزیشن با قیمت بازار
python -m services.trader.cli close --symbol SOL --execute
```

## قوانینی که ربات همیشه رعایت می‌کند

| قانون | دلیل |
|---|---|
| حد ضرر همراه خود سفارش فرستاده می‌شود | پوزیشن حتی یک لحظه هم بدون محافظ نمی‌ماند |
| بعد از باز شدن پوزیشن، وجود حد ضرر روی صرافی بررسی می‌شود. اگر نبود، دوباره ثبت می‌شود و اگر ثبت نشد، **پوزیشن فوراً بسته می‌شود** | پوزیشن بدون حد ضرر می‌تواند کل حساب را از بین ببرد |
| اندازهٔ پوزیشن از روی حد ضرر حساب می‌شود و کارمزد و لغزش قیمت را هم در نظر می‌گیرد | ضرر در صورت فعال شدن حد ضرر از بودجهٔ ریسک بیشتر نمی‌شود |
| ریسک هر معامله حداکثر ۵٪ است (پیش‌فرض ۱٪) و اهرم حداکثر ۳ برابر (قابل تنظیم تا ۲۰) | ۵ ضرر پشت سر هم با ریسک ۵٪ یعنی حدود ۲۳٪ ضرر کل حساب |
| در هر بازار فقط یک پوزیشن باز | حجم و ریسک پوزیشن بی‌صدا تغییر نمی‌کند |
| اگر ارسال سفارش timeout شد، ربات دوباره تلاش **نمی‌کند** و می‌گوید اول پوزیشن‌ها را بررسی کنید | ممکن است سفارش رسیده باشد و تلاش دوباره پوزیشن را دو برابر کند |
| پیش‌فرض Testnet است. Mainnet هم `PACIFICA_NETWORK=MAINNET` لازم دارد، هم `PACIFICA_ALLOW_MAINNET=true`، و قبل از هر ارسال باید `yes` تایپ کنید | با یک اشتباه در تنظیمات پول واقعی درگیر نمی‌شود |
